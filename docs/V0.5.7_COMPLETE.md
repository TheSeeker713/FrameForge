## Throughput (not a Partial)

Default recipe vs prior FrameForge: `-N 8`, aria2c `-x 16 -s 16 -k 1M` when on PATH, `--throttled-rate 100K`, `--http-chunk-size 10M`. Empty/header-only cookie files are never passed. Invocation snapshot and error report include `-N`, aria2 args, cookies path, `js_runtimes`, `player_client`.

**Honest limit (documented, not Partial):** YouTube may still server-throttle below NIC max. Acceptance is matching this CLI recipe with the same cookies + Deno, not saturating the NIC.

- Age/members/bot wall still need valid Netscape cookies.
