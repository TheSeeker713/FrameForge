Sequential single-active media stage is unchanged. Enqueue still does not auto-start. Pause/resume, quit policy, tray, site folders, cookies, playlists, convert, shortcuts, and the v0.4.1 refresh strategy are preserved.

## Queue clear

Live queue can drop selected jobs and all finished jobs without deleting media.

- **Clear selected** — terminal rows are hidden (`queue_hidden`) so History keeps them; pending/paused rows are deleted from SQLite only; in-flight stages are skipped.
- **Clear finished** — confirm, then hide completed + failed + cancelled from the queue. Pending/paused/downloading stay.

See [QUEUE_CLEAR.md](QUEUE_CLEAR.md). Tests: `tests/test_queue_clear_selected.py`, `tests/test_queue_clear_finished.py`, `tests/test_queue_clear_gui.py`.

## History v2

History remains SQLite-backed across launches. Clearing the queue does not erase it.

- Filters: All / Completed / Failed, domain dropdown, title/URL search.
- **Re-download selected** creates a **new pending** job (does not clobber the history row, does not arm the worker).
- **Clear selected** / **Clear all history** soft-hide (`history_hidden`) with confirm.

See [HISTORY_V2.md](HISTORY_V2.md). Tests: `tests/test_history_durable.py`, `tests/test_history_domain_filter.py`, `tests/test_history_actions.py`.

## Fail-pause

yt-dlp failures are classified (`auth_required`, `bot_check`, `rate_limited`, `not_available`, `network`, `ffmpeg`, …) with a human cause and suggested actions on the error panel.

Default **ON**: `auth_required` / `bot_check` **disarms** the worker and shows a modal (import cookies / authenticate / retry / skip & resume / stop). Remaining pending jobs stay pending. After a successful browser cookie import, FrameForge offers retry + resume.

See [FAIL_PAUSE.md](FAIL_PAUSE.md). Tests: `tests/test_fail_pause.py`, `tests/test_fail_pause_actions.py`.

## Speed

Default fast path still uses aria2c `-x 8 -s 8 -k 1M` (resume-safe) or native `concurrent_fragment_downloads = 8`. Optional **gentle rate mode** (2 s sleep + 2 MiB/s cap) is off by default; enable it after bot-check once cookies work.

See [SPEED.md](SPEED.md). Tests: `tests/test_download_speed_opts.py`.
