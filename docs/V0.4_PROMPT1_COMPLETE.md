## Pause / resume

- First-class job status `paused` (distinct from cancelled/failed; not History).
- Pause hard-kills the yt-dlp/aria2c/ffmpeg tree, keeps `.part` / control files, disarms the worker.
- Resume re-invokes download with `--continue` / `continuedl` on the same output paths.
- GUI **Pause** / **Resume** (and tray Pause current / Resume current) call worker methods.
- See [PAUSE_RESUME.md](PAUSE_RESUME.md).

## Three quit options

When a download or upscale is active (window X if close-to-tray is off, File → Quit, Ctrl+Q, tray Quit):

1. **Cancel download and quit**
2. **Pause download and quit** (stays `paused` on next launch; no auto-resume)
3. **Wait for download to complete, then quit** (disarms further claims; cancel during wait stays open)

Idle exit is immediate. Shared helper: `frameforge.gui.exit_policy`. See [TRAY_AND_QUIT.md](TRAY_AND_QUIT.md).

## Tray

- `pystray` + Pillow, `run_detached()`.
- **Close to system tray** setting default **off**.
- When on, window X hides; worker may continue. Hide does not auto-start pending downloads.
- Menu: Show window, Pause/Resume current, Quit (quit policy).

## Browser cookie auto-import

- **Import from browser** (Firefox default; then edge, chrome, brave).
- `yt-dlp --cookies-from-browser` → `%USERPROFILE%\Downloads\FrameForge\cookies\<domain>.txt`, Netscape-validated.
- Chromium lock / App-Bound Encryption: clear error + manual cookies.txt fallback.
- `auth_required` error panel: Import from browser… and Authenticate this site….
- See [COOKIES.md](COOKIES.md).
