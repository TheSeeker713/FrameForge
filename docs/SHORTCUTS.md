# Keyboard shortcuts

Reachable from **Help → Keyboard shortcuts**, **Settings → Keyboard shortcuts…**, or **F1**.

Plain letter keys are not stolen while the URL/text entry is focused unless **Ctrl** (or Alt) is held.

| Action | Keys |
|--------|------|
| Focus add URL | Ctrl+L |
| Download selected | Ctrl+D |
| Download all pending | Ctrl+Shift+D |
| Pause | Ctrl+P |
| Resume | Ctrl+Shift+P |
| Cancel selected | Ctrl+Shift+C |
| Upscale selected | Ctrl+U |
| Select recommended | Ctrl+Shift+U |
| Convert to MP3 | Ctrl+M |
| Open folder | Ctrl+O |
| Reveal file | Ctrl+Shift+O |
| Authenticate / Import cookies | Ctrl+Shift+A |
| Quit (exit policy) | Ctrl+Q |
| Queue tab | Ctrl+1 |
| History tab | Ctrl+2 |
| Thumbnails tab | Ctrl+3 |
| Open Settings | Ctrl+, |
| Keyboard shortcuts help | F1 |

Quit still uses the Prompt 1 three-option policy when a download, upscale, or convert is running.

Source of truth: `frameforge.gui.shortcuts.DEFAULT_SHORTCUTS`.
