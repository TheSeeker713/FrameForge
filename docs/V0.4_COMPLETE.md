## Prompt 2 features

### Playlists

Flat yt-dlp listing → picker with checkboxes → enqueue selected entries as **pending** jobs. Metadata (`playlist_id`, title, index) in `options_json`; queue `PL N` badge. Cap: 500 entries. See [PLAYLISTS.md](PLAYLISTS.md).

### Per-job format

Presets: Best, ≤1080p, ≤720p, ≤480p, Audio-focused. Stored on the job; download opts/CLI `-f` use the override else the global default. See [FORMATS_AND_CONVERT.md](FORMATS_AND_CONVERT.md).

### Convert selected → MP3

ffmpeg `libmp3lame -q:a 2` (VBR). Output under `Downloads\FrameForge\converted\<site_key>\`. Worker statuses `convert_pending` / `converting`. Same single-stage rule and process registry as download/upscale. See [FORMATS_AND_CONVERT.md](FORMATS_AND_CONVERT.md).

### Upscale resource monitor

psutil CPU/RAM sampler while upscaling. Sustained thresholds (default RAM 90% / CPU 95% for 8s). Status-bar warning. Optional auto-pause with reason `resource_pressure`. See [RESOURCES.md](RESOURCES.md).

### Keyboard shortcuts

Central registry wired to the same command methods as the buttons. Help: **Help → Keyboard shortcuts**, Settings, or **F1**. Quit shortcut still uses the Prompt 1 exit policy. See [SHORTCUTS.md](SHORTCUTS.md).

## Deferred (not in v0.4)
