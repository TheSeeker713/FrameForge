## P0 — why Quit failed (root cause found)

Not aspirational: Flet 0.86 runs a **separate Flet View**. Watchdog `_exit`ed Python without killing that child; `Window.destroy` wait on the UI thread deadlocked; one X fired two close handlers; tick `page.update()` during the dialog froze clicks. Full write-up: [UI_SHUTDOWN.md](UI_SHUTDOWN.md).

## P1 — aria2 first, native fallback

Do **not** disable aria2 for YouTube. When the CDN returns 403 to aria2, retry native yt-dlp once (`download_method`, `aria2_fallback_native`, `download_attempt` on the job). `aria2_forbidden` is not a fail-pause category.
