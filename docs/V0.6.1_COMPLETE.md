# v0.6.1 complete — Library grid, migrate scan, folder layout

**Package version:** 0.6.1

## What shipped

- Library grid binds one card per playable `library_items` row (count matches visible cards). Click thumb/card plays via `os.startfile`.
- Missing DB paths are re-found under `library_root` by filename. **Scan library folder** indexes orphans already on disk.
- Migrate includes completed jobs **and** videos under the download tree. Progress bar stays until a moved/failed/skipped/disk summary. Moves stay off the UI thread (cancel + quit-safe).
- Folder pick creates `<picked>/FrameForge/Library/Uncategorized` plus sibling `thumbnails/` and `database/`. Download root repair moves loose thumbs, SQLite, and videos into subfolders. See [FOLDER_LAYOUT.md](FOLDER_LAYOUT.md).
- Reset onboarding: Settings → Advanced, `python -m frameforge --reset-library`, or `.\scripts\reset_library.ps1`. Does not delete media.
- Duplicates: normalized title (brackets ignored) + size + duration; merge recycles extras.
- Junk: `.part` / `.ytdl` / zero-byte / orphan sidecars; Recycle Bin only (or Keep / Move).
