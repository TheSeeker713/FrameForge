### What closed the former PARTIALs

Netscape imports are validated; header-only stubs are not treated as cookies; smart skip / import-to-replace remains.

## History tab

Terminal jobs (`completed` / `failed` / `cancelled`) via `JobRepository.list_history` (filters + search). GUI **History** tab: timestamps, retry selected failed, **soft-hide** (not DB delete). Survives app relaunch (SQLite). See [`docs/HISTORY.md`](HISTORY.md).

## Thumbnails

Probe/download caches thumbs under `Downloads\FrameForge\thumbnails\`. Queue/History rows show a cached 48×36 preview or placeholder. **Thumbnails** tab grids recent thumbs; click focuses the job. Failures are non-fatal. See [`docs/THUMBNAILS.md`](THUMBNAILS.md).

## Robust error handling

Categories persisted in `options_json.error_category`: `auth_required`, `network`, `ffmpeg`, `blocked_4k`, `cancelled`, `unknown`. Panel shows category + message + next action. Handler exceptions mark the job failed/cancelled and **do not** kill the worker loop. Startup recovery still requeues interrupted `downloading`/`upscaling` to `pending`.
